# Important Information Page

The fourth dashboard page contains:
- Editable install turnaround times by county
- Editable MTD installs for active agents in Admin display order
- Editable extra-sensor cost matrix

All data is stored under `targets/main.infoPage`, so the existing targets permissions are reused and no additional Firestore collection is required.
