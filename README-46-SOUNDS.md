# Active Sale Sounds

The dashboard uses the numbered range `sale-sound-8.mp3` through `sale-sound-57.mp3`, excluding:

- `sale-sound-9.mp3`
- `sale-sound-11.mp3`
- `sale-sound-20.mp3`
- `sale-sound-32.mp3`

This gives 46 active sounds. The shuffle bag plays every active sound once before any active sound repeats. The queue persists across browser refreshes, and the first sound of a new cycle cannot equal the final sound of the previous cycle. Sounds remain limited by the nine-second sale celebration.

Asset version: `20260918-7`.
