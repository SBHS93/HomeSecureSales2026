- Agent Performance keeps all five compact KPI cards.
- Achievements & Momentum shows Daily, Weekly, Monthly, Weekly GATE, and GATE Left.
- Start Cycle enables automatic 30-second page rotation.
- Stop Cycle disables automatic rotation.
- Manual arrows work in both modes.
- The cycle selection is remembered in the browser.
- CORE and Extras reduce GATE Left; SWEEP does not.
